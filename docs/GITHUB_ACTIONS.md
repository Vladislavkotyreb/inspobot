# Запуск в GitHub Actions

Бесплатная альтернатива серверу: GitHub раз в сутки поднимает раннер, тот
собирает подборку и гаснет. Ни VPS, ни оплаты, ни возни с доступом к Anthropic
из России — раннеры стоят в США.

Расписание — [`.github/workflows/daily.yml`](../.github/workflows/daily.yml).

## Что завести в настройках репозитория

**Settings → Secrets and variables → Actions → Secrets:**

| Секрет | Откуда взять |
|---|---|
| `ANTHROPIC_API_KEY` | console.anthropic.com, ключ **внутри workspace** |
| `TELEGRAM_BOT_TOKEN` | @BotFather |
| `TELEGRAM_CHAT_ID` | ваш id; подскажет `python -m inspobot.doctor` |
| `MOBBIN_TOKEN_JSON` | содержимое `var/mobbin_token.json` целиком |
| `GH_SECRETS_TOKEN` | токен GitHub с правом записи секретов, см. ниже |

Необязательные: `TELEGRAM_CHAT_IDS` — список получателей, по одному id в
строке (заменяет `TELEGRAM_CHAT_ID`); `ANTHROPIC_WORKSPACE_ID` — если ключ
выпущен на уровне организации.

Содержимое токена Mobbin удобно скопировать так:

```bash
cd ~/Desktop/inspobot && cat var/mobbin_token.json | pbcopy
```

**Settings → Secrets and variables → Actions → Variables** (не секреты, видны
всем — здесь только настройки):

| Переменная | По умолчанию |
|---|---|
| `ANTHROPIC_MODEL` | `claude-sonnet-5` |
| `INSPOBOT_EFFORT` | `medium` |
| `INSPOBOT_IMAGE_MODE` | `photo` |
| `INSPOBOT_TZ` | `Europe/Moscow` |

## Токен для записи секретов

Нужен из-за того, как устроен доступ к Mobbin. Их авторизация на Supabase, а
тот при каждом обновлении выдаёт новый refresh-токен и **гасит старый**.
Раннер живёт один запуск и ничего не помнит, поэтому обновлённый токен надо
положить обратно в секрет — иначе завтрашний запуск останется без доступа.

Создать: **Settings → Developer settings → Personal access tokens →
Fine-grained tokens → Generate new token**.

- Repository access: **Only select repositories** → `inspobot`
- Repository permissions → **Secrets: Read and write**
- Больше ничего не давать. Срок — на ваш вкус, но не «без срока».

Получившийся токен положить в секрет `GH_SECRETS_TOKEN`.

Без него всё будет работать до первого обновления токена Mobbin (примерно час),
а потом сломается. В логе на этот случай появится предупреждение.

## Первый запуск

**Actions → Утренний дайджест → Run workflow.** Для пробы поставьте галочку
*Только показать в логе* — подборка соберётся, но никуда не уйдёт. Убедились,
что всё зелёное — запустите ещё раз без галочки, с *Отправить, даже если
сегодня уже слали*.

## Что стоит знать заранее

**Время неточное.** Cron в Actions — не будильник: под нагрузкой запуск
сдвигается на десятки минут. Стоит `7 8 * * *` (11:07 МСК), а придёт письмо
где-то между одиннадцатью и двенадцатью. Точное время — только на своём
сервере или на Маке.

**Память о показанном живёт в кэше** и может пропасть: GitHub вычищает кэши
старше недели и при переполнении. Худшее следствие — повторится уже
показанный экран. При ежедневных запусках кэш не успевает протухнуть.

**Состав дайджеста лежит в репозитории**, в `config/profile.json`. Правится
локально через `python -m inspobot.setup_cli` (укажите
`INSPOBOT_PROFILE=config/profile.json`) и коммитится — так изменения расписания
видны в истории.

**Не добавляйте в workflow триггер `pull_request`.** Сейчас он запускается
только по расписанию и вручную, поэтому секреты недоступны никому постороннему.
Триггер на PR из форка — самый популярный способ утечь секретами.

Репозиторий имеет смысл сделать приватным: код открытым быть может, а вот
лишний повод разбираться с чужими форками — нет.

## Если что-то сломалось

Логи: **Actions → нужный запуск → Собрать и отправить**. Секреты в них не
попадают, тела запросов не печатаются.

Токен Mobbin протух (в логе `MobbinAuthError`) — обновите вручную:

```bash
cd ~/Desktop/inspobot
.venv/bin/python -m inspobot.auth_cli
cat var/mobbin_token.json | pbcopy
```

и вставьте в секрет `MOBBIN_TOKEN_JSON` заново.
